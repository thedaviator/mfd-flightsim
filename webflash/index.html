MFD display firmware

Install or update the firmware from this page. Use Chrome or Edge on a computer; nothing else is needed.

  1. On the back of the display, slide the switch next to BOOT to UART1.
  2. Connect the USB cable to the port marked UART1.
  3. Hold BOOT, press and release RESET, then release BOOT.
  4. Click Install and choose the port called USB-Enhanced-SERIAL CH343.
  5. When it finishes, move the cable to the port marked USB. The display starts. If this is its first start, set up WiFi on the Settings page.
This browser can't talk to USB devices. Use Chrome or Edge on a computer. This page must be opened over https.

Your WiFi settings are kept unless you tick "Erase device" in the installer.
