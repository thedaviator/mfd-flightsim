Flight-sim MFD: Quick Start

A Garmin-style touchscreen display for Microsoft Flight Simulator and X-Plane 12

You need:

  • The display (Waveshare ESP32-S3-Touch-LCD-7)
  • A USB-C cable that carries data (some cables only charge)
  • A Windows 10 or 11 PC (64-bit) running MSFS 2020/2024 or X-Plane 12
  • A WiFi network that the PC is also on
2.4 GHz WiFi only. The display cannot join 5 GHz-only networks. Most home routers broadcast both bands under one name, so this usually just works. If the display cannot connect, check that your router has 2.4 GHz turned on.

1Install MFD Bridge on the sim PC

  1. Run MFD-Bridge-Setup.exe. If Windows shows "Windows protected your PC", click More info, then Run anyway. The installer is not code-signed.
  2. Setup checks the PC first and lists what it found on the Ready to Install page: Windows version, the Microsoft Visual C++ runtime, and any installed simulators. It installs anything missing by itself. You don't need to install Python or anything else.
  3. Tick Start MFD Bridge with Windows if you want it running whenever you fly.
  4. The installer also allows MFD Bridge through Windows Firewall, so the display can reach it.

The MFD Bridge window shows three status lights: Simulator, Display and This PC. The last one shows the PC's name and network address.

2Power up the display

The display has two USB-C ports on the back. For normal use, plug the cable into the one marked USB:

[UART1] <- only for firmware updates [ USB ] <- normal use: power for the display

On first start the display opens its Settings page (the gear key on the bottom row).

3Connect the display to WiFi

  1. Tap your network in the list. Tap SCAN if it isn't shown.
  2. Type the password on the on-screen keyboard. SHOW lets you check it. Tap ✓ to close the keyboard.
  3. Leave BRIDGE PC empty. The display finds the PC by itself.
  4. Tap SAVE & CONNECT. The status box turns green: WiFi: YourNetwork IP …, then Bridge: connected.

The settings are saved in the display and survive power-offs and firmware updates.

If the status stays on Bridge: searching…, your network may block broadcasts (guest WiFi, some mesh systems). Click Copy address in the MFD Bridge window, type that address into BRIDGE PC on the display, and tap SAVE & CONNECT again.

4Fly

Start the simulator and load a flight. MFD Bridge detects MSFS or X-Plane automatically, the Simulator light turns green, and the display comes alive. To try everything without a simulator, set Simulator to Demo flight in MFD Bridge and click Apply.

Top-bar shortcuts: tap COM or NAV to tune, long-press to swap. Tap XPDR to enter a squawk. Long-press XPDR for a status window with WiFi, link and frame rate.

To show a complete route on the map, pick your .pln (MSFS) or .fms (X-Plane) file under Flight plan in MFD Bridge and click Apply. The simulators only share the current leg.

5Updating the display firmware

Each new version of MFD Bridge includes the matching display firmware. After you install it, the display shows FIRMWARE … AVAILABLE:

  1. On the display, open Settings (the gear key).
  2. Tap INSTALL. The display downloads the update over WiFi, shows the progress, and restarts after about a minute. Keep it powered until it has restarted.

Your settings are kept. If the update is interrupted, the display keeps running the firmware it had.

First install or recovery (USB): only needed for a display that has never had this firmware, or one that no longer starts.

  1. On the back of the display, slide the small switch next to BOOT to UART1.
  2. Move the cable to the port marked UART1. The screen may stay dark, which is normal on this port.
  3. Hold BOOT, press and release RESET, then release BOOT.
  4. In MFD Bridge click Update display over USB…, check the port, then click Update.
  5. When it says Done, move the cable back to the USB port.

Troubleshooting

You seeDo this
Screen stays darkTouch it: it may be asleep (see SCREEN SLEEP on the Settings page; it also wakes by itself when a flight starts). Otherwise make sure the cable is in the USB port. On the UART1 port the display waits for a firmware update and stays dark. Press RESET.
Screen dims, then goes darkScreen sleep: no flight data for the time set under SCREEN SLEEP on the Settings page (default 10 minutes). It wakes when flight data arrives or when you touch it; that first touch only wakes it. Choose OFF to keep it on.
SETUP WIFI or NO WIFI (top right)Open Settings (gear key) and check the network name, the password, and that 2.4 GHz is on.
NO BRIDGEIs MFD Bridge running on the PC? Is the PC on the same network? Try the bridge address step in section 3.
NO SIM / NO FLIGHT DATAThe display is connected but no simulator is sending data. Start a flight. For X-Plane on another PC, enter that PC's address under X-Plane PC in MFD Bridge.
Radio or autopilot buttons do nothing in some aircraftSome aircraft (G1000 NXi, G3000, many add-ons) use their own controls instead of the simulator's standard ones. Most default general-aviation aircraft work.
No INSTALL button although MFD Bridge says an update is readyOpen the Settings page; the button sits next to the firmware version. Check that the display is connected to this PC's MFD Bridge (Settings: Bridge: connected).
USB firmware update can't connectCheck the UART1 switch and that the cable is in the UART1 port, then repeat the BOOT/RESET step. Close 3D-printer software (Cura, PrusaSlicer): it grabs serial ports.
Neither simulator gives add-ons weather-radar or lightning data, so MFD Bridge downloads real-world weather: RainViewer radar (worldwide where there are weather radars) and NOAA GOES satellite lightning (the Americas only). It matches what you see when the sim uses live weather. Flying with preset weather or without internet? Choose Simulated storms under Weather page in MFD Bridge; the page then labels them SIMULATED. METARs on the NRST page also come from the internet (aviationweather.gov) and can be turned off there.
